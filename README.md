# jarvis-seo

SEO client prototype site — built with Next.js, Tailwind CSS, and TypeScript.

## Live Prototypes

- [Nisarga Cure](https://jarvis-seo.vercel.app/clients/nisargacure) — Naturopathy & Wellness, Raipur, India | [Live Site](https://nisargacure.com/)

---

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.
